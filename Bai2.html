Bài 2: Công thức lượng giác

Kiến thức trọng tâm:

  • Công thức cộng

    • "sin thì sin cos cos sin"

    sin( a + b ) = sina.cosb + cosa.sinb

    sin ( a - b ) = sina.cosb - cosa.sinb

    "cos thì cos cos sin sin dấu trừ"

    cos ( a + b ) = cosa.cosb - sina.sinb

    cos( a - b ) = cosa.cosb + sina.sinb

    "tan thì ta tổng hai tan, chia cho 1 trừ tan ta tan mình"

    tan ( a + b ) = \(\frac{tana + tanb}{ 1 - tana.tanb}\)

    tan ( a - b ) = \(\frac{tana - tanb}{1 + tana.tanb}\)

  • Công thức nhân đôi

    • sin2a = 2sina.cosa

    cos2a = cos²a - sin²a = 1 - 2sin²a = 2cos²a - 1

    tan2a = \(\frac{2tan}{1 - tan²a}\)

    Chứng minh công thức nhân đôi

    sin2a = sin( a + a) = sina.cosa + cosa.sina = 2sina.cosa

    cos2a = cos( a + a) = cosa.cosa - sina.sina = cos²a - sin²a (1)

    Ta có: sin²a + cos²a = 1 (*)=> cos²a = 1 - sin²a, thay vào (1) => (1) = 1 - sin²a - sin²a = 1 - 2sin²a

    Từ (*) => sin²a = 1 - cos²a, thay vào (1)=> (1) = cos²a - ( 1 - cos²a ) = cos²a - 1 + cos²a = 2cos²a - 1

    tan2a = tan( a + a ) = \(\frac{tana + tana}{1 - tana.tana}\) = \(\frac{2tana}{1 - tan²a}\)
