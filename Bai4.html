Bài 4: Phương trình lượng giác cơ bản

Kiến thức trọng tâm

  • Phương trình tương đương

    • \(f(x) = 0 \Leftrightarrow g(x) = 0\)

    Từ lúc này giải phương trình sẽ dùng dấu tương đương, kí hiệu \(\ \Leftrightarrow\)

    sinx = m (\(\ -1 \le m \le 1\))

    sinx = m \(\Leftrightarrow\) sinx = sinα

    \(\Leftrightarrow\) \(\left[ \begin{array}{1} x = α + k2π \\ x = π - α + k2π \end{array} \right.\) ( k \(\in\) Z)

    cosx = m (\(\ -1 \le m \le 1\))

    cosx = m \(\Leftrightarrow\) cosx = cosα

    \(\Leftrightarrow\) \(\left[ \begin{array}{1} x = α + k2π \\ x = - α + k2π \end{array} \right.\) ( k \(\in\) Z)

    tanx = m

    tanx = m \(\Leftrightarrow\) tanx = tanα \(\Leftrightarrow\) x = α + kπ ( k \(\in\) Z)

    cotx = m

    cotx = m \(\Leftrightarrow\) cotx = cotα \(\Leftrightarrow\) x = α + kπ ( k \(\in\) Z)
